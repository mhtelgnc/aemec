AEMEC — Site vitrine statique

Fichiers:
- index.html : page principale
- style.css  : design responsive
- logo-aemec.jpg : logo fourni

Utilisation:
1. Décompresser le dossier.
2. Ouvrir index.html dans un navigateur.
3. Pour mettre le site en ligne, envoyer ces fichiers sur un hébergement statique (ou un hébergement web classique).

À compléter avant publication (emplacements déjà prévus dans index.html, cherchez "À compléter" / "à remplacer"):
- adresse officielle / siège → section Contact
- présentation officielle de l'association → section À propos
- date de création et statuts → section À propos
- liste des ministères membres → section "Ministères membres" (id="membres")
- événements et actualités → section "Actualités & activités" (id="activites")
- liens Facebook / YouTube / WhatsApp → icônes dans le footer (remplacer href="#" par les vraies URLs)
- photo du président → remplacer .portrait-placeholder par une <img> dans la section Présidence
